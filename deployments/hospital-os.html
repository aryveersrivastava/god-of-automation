System Architecture

End-to-End Autonomous Execution Topology

6-Node High-Concurrency Routing Architecture
Node 01

Inbound WhatsApp Webhook

Ingests live patient messages & audio notes with sub-50ms latency verification.

Node 02

n8n Logic Router

Parses payload JSON, authenticates session token, and branches intent workflows.

Node 03

Gemini 2.0 Flash NLU

Executes intent classification, doctor slot extraction, and clinical symptom triage.

Node 04

Supabase State Manager

Maintains ACID conversation state, doctor calendars, and patient EHR records.

Node 05

Expiring S3 Token Generator

Generates encrypted, time-bound diagnostic report links expiring in 7 days.

Node 06

Automated Dispatch Bridge

Dispatches instant booking confirmation or escalates red flags to on-call doctors.

Real-time semantic symptom classifier identifying emergency indicators (chest pain, acute distress) and routing alerts immediately to on-call medical personnel.

Autonomous scheduled triggers sending multi-touch confirmation and reminder notifications across WhatsApp and SMS, reducing clinic no-show rates by up to 40%.
