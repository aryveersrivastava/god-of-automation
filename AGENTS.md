# Project Execution & Memory Protocols

## Mandatory Workflow for Every Task:
1. **SEARCH**: Query and identify relevant skills from `.agent/skills/` and `~/.gemini/config/skills/` before starting any design, coding, automation, or document processing task.
2. **PLAN**: Load the skill instructions and formulate a structured architectural and visual plan. Follow the skill's specific heuristics, tokens, and rules.
3. **WRITE**: Write clean, production-grade, highly-aesthetic, type-safe, and accessible code/content. Avoid generic AI templates.
4. **EXECUTE**: Run commands, builds, or tests to ensure functional correctness.
5. **VERIFY**: Run verification checks (accessibility, responsiveness, performance, visual polish).
